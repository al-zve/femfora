# FemFora — заметки для разработки

- Интерфейс на русском. О пользовательнице — в женском роде («Ты справилась»), о других женщинах — феминитивы.
- Local-first: данные только в IndexedDB (Dexie, `src/db.ts`). Никакой облачной БД, аналитики, трекеров, сторонних шрифтов с CDN.
- Данные о здоровье и цикле никогда не уходят с устройства. Наружу могут уходить только названия и время задач: в Google (календарь «FemFora», список «FemFora Inbox»). AI не используется: оценка нагрузки — правилами на устройстве.
- Серверная часть — только Cloudflare Pages Functions в `functions/` (обмен OAuth-токенами WHOOP и Google), без хранения данных. Исключение: KV `WHOOP_HANDOFF` держит зашифрованный ключом устройства результат первого входа (WHOOP и Google, префикс `g-`) до 15 минут.
- Google: права только `calendar.app.created` и `tasks`, OAuth-приложение в статусе «In production» (в «Testing» refresh-токены живут 7 дней). Переменные `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`.
- Дизайн: токены в `src/styles.css` (светлая и тёмная тема), шрифт Nunito локально, кнопки трёх видов: `btn-primary`, `btn-secondary`, `btn-text`.
- Батарейка: зоны 67/34 %, цвета бирюзовый / нежно-розовый / фуксия (`src/lib/battery.ts`).
- Перед коммитом: `npm run build` без ошибок.
- Перед каждым пушем поднимай версию в `package.json` (patch для правок, minor для этапов): Aly видит её внизу настроек и по ней понимает, что обновление дошло.
