# FemFora — заметки для разработки

- Интерфейс на русском. О пользовательнице — в женском роде («Ты справилась»), о других женщинах — феминитивы.
- Local-first: данные только в IndexedDB (Dexie, `src/db.ts`). Никакой облачной БД, аналитики, трекеров, сторонних шрифтов с CDN.
- Данные о здоровье и цикле никогда не уходят с устройства. В AI можно отправлять только тексты задач.
- Серверная часть — только Cloudflare Pages Functions в `functions/` (обмен OAuth-токенами), без хранения данных.
- Дизайн: токены в `src/styles.css` (светлая и тёмная тема), шрифт Nunito локально, кнопки трёх видов: `btn-primary`, `btn-secondary`, `btn-text`.
- Батарейка: зоны 67/34 %, цвета бирюзовый / нежно-розовый / фуксия (`src/lib/battery.ts`).
- Перед коммитом: `npm run build` без ошибок.
