# FemFora

Трекер задач, который планирует день по силам: учитывает восстановление, сон и фазу цикла.

- PWA, работает с домашнего экрана iPhone
- Все данные хранятся только на устройстве (IndexedDB), без аналитики и сторонних скриптов
- Резервная копия шифруется паролем (AES-GCM, PBKDF2)

## Разработка

```bash
npm install
npm run dev      # локально
npm run build    # проверка типов + сборка в dist/
```

Хостинг: Cloudflare Pages, сборка `npm run build`, папка `dist`.

## Этапы

1. Таск-трекер: задачи, подзадачи, комментарии, дедлайны, перенос, календарь ✅
2. WHOOP: recovery и сон (Pages Function для обмена токенами) ✅
3. Цикл: отметки, прогноз, фазы на графиках, наблюдения, импорт истории из Maya (CSV, только даты, на устройстве) ✅
4. Движок плана дня: умный перенос, предупреждение при добавлении, прогноз недели, фаза по личным данным ✅
5. Оценка нагрузки задачи по тексту — правилами на устройстве, без AI ✅
6. Google: напоминания через календарь «FemFora», входящие из Google Tasks «FemFora Inbox» ✅
